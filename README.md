# 📚 Glossário

## Prompt

Instrução enviada para a IA.

## Token

Unidade utilizada para processar texto.

## Contexto

Informações fornecidas para melhorar a resposta.

## IA Generativa

Modelos capazes de criar texto, imagens e código.
